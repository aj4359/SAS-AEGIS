# AEGIS: BEFORE

**Know yourself before you look for somebody else.**

AEGIS is a private, reflective Personal Readiness / Self-Knowledge experience from TA GuruLabs.

It does not match people. It does not swipe. It does not promise a partner. It turns the torch toward the person doing the looking.

## v2 journey

BEGIN → SELF → READINESS → RESILIENCE → OPENNESS → MIRROR → REFLECTION

**Complex underneath. Simple on top.** One meaningful question at a time.

## Product law

- Human choice is sovereign.
- Uncertainty stays visible.
- No pseudo-scientific readiness score.
- No clinical diagnosis or prediction of relationship success.
- Pause, skip, revise, delete and exit remain available.
- Private reflection is separated from product analytics.
- No intimate reflection data for advertising or hidden ranking.

## Working Proof #001 — The Mirror Test

Before: **“I think I'm ready to date.”**

After: **“What do I understand about myself now that I didn't understand 20 minutes ago?”**

The prototype is successful only if consenting participants gain useful self-understanding without feeling judged, manipulated or scored.

## Left-Field Rule

> Don't build a better version of what everybody can already see. Shine the light somewhere else.
